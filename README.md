## Projetos em destaque

### FIAP Tech Challenge — Plataforma de OS para oficinas mecânicas
Sistema completo em microsserviços para gestão de ordens de serviço, com autenticação por CPF via Lambda Authorizer, billing integrado ao Mercado Pago e execução de OS com controle de estoque.
- **Stack**: NestJS · TypeScript · MySQL · AWS Lambda · API Gateway · EKS · Terraform
- **Arquitetura**: 4 microsserviços + auth Lambda + IaC completo (RDS, EKS, VPC)

### FIAP Hackathon IADT+SOAT — Análise de diagramas com IA
Pipeline event-driven para upload, análise por IA (Gemini Vision + Groq) e geração de relatórios técnicos sobre diagramas de arquitetura.
- **Stack**: NestJS · TypeScript · MongoDB · MySQL · S3 · SQS · Gemini · Groq
- **Arquitetura**: 5 microsserviços (BFF, Upload Orchestration, Processing, Report, Auth) + EKS + Helm + Terraform
